# Contributing

Thanks for your interest in **levilabs/laravel-wayl**.

This project is maintained by **[Levi Labs](https://levilabs.dev)** ([GitHub](https://github.com/levilabs-dev)) and **Nizam Omer** ([nizaamomer.com](https://nizaamomer.com)).

## Before you open a PR

1. Open an issue for larger changes so we can align on approach.
2. Run the test suite and static analysis:

   ```bash
   composer test
   composer analyse
   composer format
   ```

3. Follow existing code style (Laravel Pint is configured in this repo).

## Security issues

Do **not** open a public issue for vulnerabilities. See [SECURITY.md](SECURITY.md).
